# 📊 DS Mini Project

## 📌 Project Overview
This is a **Data Science Mini Project** that demonstrates the use of modern tools and technologies to build, analyze, and present data-driven solutions.

The project includes frontend setup, configurations, and necessary files for building and running the application.

---

## 🚀 Features
- 📈 Data analysis and visualization
- ⚡ Fast and modern development setup
- 🎨 Clean UI components
- 🛠️ Modular and scalable structure

## ⚙️ Installation & Setup

1. Clone the repository:
git clone https://github.com/Sanskruti-Neharkar/Ds-Mini-project.git

2. Go to folder:
cd Ds-Mini-project

3. Install:
npm install  
or  
bun install  

4. Run:
npm run dev  
or  
bun run dev  

---

## 📊 Usage
Open in browser after running.
